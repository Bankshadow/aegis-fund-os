## 2. นิยาม (เหมือน E59 ทุกบรรทัด ห้ามแก้)

Base = S003 ตาม `docs/S003_SPEC.md` · flow ตาม BORA §5–§9:
`Delta = TakerBuyQuote − (Quote − TakerBuyQuote)` · `Delta_Z` = z-score 100 แท่ง ·
`PriceImpact = |close−open| / ATR(14)` · `AbsorptionScore = |Delta_Z| / (PriceImpact + 0.10)`

**หนึ่งไม้ต่อเหรียญ · ตัวกรองประเมินที่แท่งสัญญาณ ตัดสินก่อนเข้าไม้ · ไม่แตะ stop/target**

| แขน | กฎ |
|---|---|
| **M0** | S003 เปล่า — baseline |
| **M1** | flow **ยืนยัน** absorption (BORA §10/§11): SHORT ต้อง `Delta_Z >= +Zt` · LONG ต้อง `Delta_Z <= −Zt` |
| **M2** | `|Delta_Z| >= Zt` ไม่สนทิศ |
| **M3** | AbsorptionScore อยู่ percentile `q` บนสุดของ 100 แท่งย้อนหลัง |
| **M4** | **Group B**: ส่วนเติมเต็มของ M1 |
| **C** | **Group C (PATCH 1)**: สุ่มเก็บที่ duty เท่ากับแขนที่เทียบ × **20 seeds** (seed 9500+i) |

`Zt ∈ {1.5, 2.0, 2.5}` · `q ∈ {90, 95}` · **ค่าหลัก `Zt = 2.0`** (ตัวเลขของ BORA เอง)
