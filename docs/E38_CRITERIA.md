## 0. นี่คือการ "ระบุสเปก" ไม่ใช่การ "ตรวจสอบกลยุทธ์"

E37 ได้ **WR 75%** (อ้าง 78% — ตรง) แต่ **20 เทรด** (อ้าง 73 — ไม่ตรง)
คำถามเดียวของ E38: **การอ่านสเปกแบบไหนให้ลายนิ้วมือทั้งสองตัวพร้อมกัน**

**กับดักที่ต้องประกาศวิธีกันไว้ก่อน** — การไล่ปรับกฎจนได้ 73 เทรดคือการ fit
เข้าหาเป้า ซึ่งเกณฑ์ E37 §7 ห้ามไว้เอง วิธีกัน:

| กฎ | เหตุผล |
|---|---|
| **แขนทุกแขนประกาศครบก่อนรัน** ห้ามเพิ่มหลังเห็นผล | ไม่งั้นคือการค้นจนเจอ |
| **ใช้ (จำนวนเทรด, WR) ระบุสเปกเท่านั้น ห้ามใช้ผลตอบแทนเลือกแขน** | จำนวนเทรดเป็นลายนิ้วมือเชิงโครงสร้าง ไม่ใช่ผลงาน — การจับคู่ด้วยมันจึงไม่ overfit ผลตอบแทน |
| **รายงาน robust ของทุกแขน ทุกหน้าต่าง เสมอ** | แขนที่ตรงลายนิ้วมืออาจขาดทุน — นั่นก็คือคำตอบ |
| **ถ้าไม่มีแขนไหนตรงทั้งสองตัว → รายงานว่าระบุไม่ได้ แล้วหยุด** | ห้ามขยับเกณฑ์ให้ตรง |

**ระบุสเปกได้ ≠ กลยุทธ์ใช้ได้** ต่อให้เจอแขนที่ตรง 73/78% ก็ยังต้องผ่าน
P2–P7 ของ E37 ถึงจะนับว่าอะไรก็ตาม

## 4. เกณฑ์

### 4.1 การระบุสเปก (I)

| id | เกณฑ์ |
|---|---|
| **I1** | จำนวนเทรดต่างจาก **73** ไม่เกิน **±25%** (คือ 55–91) |
| **I2** | WR ต่างจาก **78%** ไม่เกิน **±10 จุด** (คือ 68–88%) |
| **I3** | ต้องมี **แขนเดียวเท่านั้น** ที่ผ่านทั้ง I1 และ I2 บน W1 |

**ถ้าไม่มีแขนไหนผ่าน I1+I2 → ระบุไม่ได้ รายงานแล้วหยุด**
**ถ้ามีหลายแขนผ่าน → รายงานทุกแขนที่ผ่าน ห้ามเลือกอันที่กำไรดีที่สุด**

### 4.2 ผลงานของแขนที่ระบุได้ (เกณฑ์เดิมจาก E37 ไม่ลดลง)

robust = `return − 2 × maxDD`

| id | เกณฑ์ |
|---|---|
| Q1 | robust > 0 **ทั้ง W1 และ W2** |
| Q2 | ชนะ buy & hold ด้วย robust ทั้งสองหน้าต่าง |
| Q3 | liquidation = 0 และไม่ ruin |
| Q4 | held-out ETH และ SOL robust > 0 — ประเมินเฉพาะเมื่อ Q1–Q3 ผ่าน |

## 5. ตารางการตัดสินใจ (เขียนก่อนเห็นผล)

| ผลลัพธ์ | อ่านว่า | ทำอะไรต่อ |
|---|---|---|
| ไม่มีแขนผ่าน I1+I2 | ยังระบุสเปกไม่ได้ | รายงานช่องว่างที่เหลือ **หยุด ห้ามเพิ่มแขน** |
| ระบุได้ + Q1/Q2 ผ่าน | สเปกที่รายงานอาจมีของจริง | บันทึกเป็นผู้สมัคร · ยังห้ามเทรดจริง · ต้องมี held-out |
| **ระบุได้ แต่ Q1/Q2 ตก** | **ตัวเลขที่โฆษณามาจากการอ่านที่ขาดทุน** | รายงานตรง ๆ — นี่คือผลที่มีค่าที่สุด |
| หลายแขนผ่าน I1+I2 แต่ผลตอบแทนต่างกันมาก | ลายนิ้วมือแยกสเปกไม่ได้ | ⚖️ รายงานช่วงของผลลัพธ์ทั้งหมด |
