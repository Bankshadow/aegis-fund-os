## 2. Candidate (ประกาศครบ ห้ามเพิ่ม)

**ใช้เฉพาะราคาปิด — ไม่มีการเปรียบเทียบ high/low แบบไม่ต่อเนื่อง**
นี่คือเหตุผลเชิงโครงสร้างที่คาดว่าจะรอดด่าน noise (จะถูกทดสอบ ไม่ใช่สมมติ)

| id | logic |
|---|---|
| **M1-LO** | **TSMOM long-only**: ถือ long เหรียญที่ผลตอบแทน k วัน > 0 · น้ำหนัก ∝ 1/σ₂₀ |
| **M1-LS** | **TSMOM long-short**: long ถ้า r_k > 0, short ถ้า < 0 · น้ำหนัก ∝ 1/σ₂₀ |
| **M2** | **cross-sectional**: จัดอันดับด้วย r_k · long ควินไทล์บน / short ควินไทล์ล่าง เท่ากันทุกตัว |

**k (lookback) = 30 วัน คือค่าหลักที่ประกาศไว้** · รายงาน k = 7 และ 14 ด้วย
**เพื่อดูว่าผลขึ้นกับ k ไหม ไม่ใช่เพื่อเลือก k ที่ดีที่สุด — ห้ามเลือก**

**กติกาที่ล็อกไว้ทุกแขน**:
- rebalance ทุก **7 วัน** · gross exposure = **1.0 เสมอ (ไม่มี leverage)**
- σ = ผันผวน 20 วันของผลตอบแทน log · น้ำหนักถูก normalize ให้ gross = 1.0
- ต้นทุน = turnover × fee/ข้าง · **กรณีฐาน 0.15%/ข้าง** (เพดานจาก E50)

**เกณฑ์เทียบ**: equal-weight buy&hold ของจักรวาล และ BTC buy&hold

run count = 3 logic × 3 k × 1 fee = 9 + benchmark · ไม่มีการกวาดค่าอื่น
