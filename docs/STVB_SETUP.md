## 1. กติกาเต็ม (ทุกบรรทัดเป็นตัวเลขตายตัว ไม่มีดุลพินิจ)

### 1.1 จักรวาล

- เหรียญที่มีประวัติราคา **≥ 400 แท่งรายวัน** ณ วันตัดสิน
- ตัดเหรียญที่ปริมาณซื้อขายเฉลี่ย 30 วัน **< 20 เท่าของขนาดไม้ที่ตั้งใจ** ออก
  (ข้อนี้ **ไม่ได้ถูกทดสอบ** ในแบ็คเทสต์ — ดู §4 ข้อ 4)
- เหรียญถูก delist = ปิดสถานะที่ราคาปิดสุดท้าย ไม่ถือต่อ

### 1.2 สัญญาณ — โหวต 3 ตัวกรอง ไม่มีการเลือก

ต่อเหรียญ ต่อวัน นับว่ากี่ข้อเป็นจริง:

1. `close > SMA(200)`
2. Donchian-55: ล่าสุด `close` ทะลุ **สูงสุด 55 วันก่อนหน้า** → state = long ·
   ทะลุ **ต่ำสุด 55 วันก่อนหน้า** → state = flat · ระหว่างนั้นคง state เดิม
3. `SMA(50) > SMA(200)`

**conviction = จำนวนโหวต ÷ 3** ∈ {0, 0.33, 0.67, 1.00}

> เหตุผลที่ต้องโหวต ไม่ใช่เลือกตัวที่ดีที่สุด: E30 §C7 วัดแล้วว่าการเลือกตัวกรองที่
> backtest สวยที่สุดถูกต้อง 2/10 = **เท่ากับการสุ่ม**

### 1.3 ขนาดไม้ — inverse volatility แล้วคุมที่ระดับพอร์ต

```
vol_j      = ส่วนเบี่ยงเบนมาตรฐานของผลตอบแทนรายวัน 20 วัน × sqrt(365)
raw_j      = conviction_j / vol_j                     (เฉพาะ conviction > 0)
est_vol    = Σ (raw_j × vol_j)                        (สมมติ correlation = 1 — ตั้งใจให้แง่ร้าย)
w_j        = raw_j × (0.40 / est_vol)                 (vol target 40%/ปี)
ถ้า Σ|w_j| > 1.00  →  หารทั้งหมดด้วย Σ|w_j|           (gross cap 1.00)
```

- **gross ห้ามเกิน 1.00 เด็ดขาด — ห้าม leverage ทุกรูปแบบ**
- ไม่มีเหรียญใด conviction > 0 → **ถือเงินสด 100%** (นี่คือสถานะปกติ ไม่ใช่ความล้มเหลว)

> เหตุผลที่ห้าม leverage: E32 วัด vol drag ได้ **−42%/ปี ที่ 2x, −97%/ปี ที่ 3x**
> บวก funding 27.7%/ปี ที่ 2x · และ frontier แสดงว่า **ตัวเดียวกันที่ 2x
> แย่กว่าถือ BTC เฉย ๆ ในทุกงบความเสี่ยง**

### 1.4 การลงมือ

- **รีบาลานซ์ทุก 5 แท่ง** (ประมาณสัปดาห์ละครั้ง) ระหว่างนั้นไม่แตะ
- สัญญาณจากแท่งปิด `i` ลงมือได้ตั้งแต่ `close[i]` ถึง `close[i+1]` —
  ทดสอบแล้วว่า lag 1 วันทำให้ผลต่าง **0.1 จุด** (E33 H9) จึงไม่ต้องรีบ
- ต้นทุนที่ใช้ในแบ็คเทสต์: **0.15%/ขา** (taker + slippage) spot เท่านั้น

### 1.5 กฎหยุด (ประกาศล่วงหน้า ไม่ใช่ดุลพินิจตอนขาดทุน)

| เงื่อนไข | การกระทำ |
|---|---|
| drawdown ของพอร์ต **> 60%** จากจุดสูงสุด | **หยุดทั้งระบบ** ทบทวนก่อนเริ่มใหม่ (แบ็คเทสต์เจอ 54.4% — เกิน 60% แปลว่าอยู่นอกช่วงที่เคยวัด) |
| ไม่มีเหรียญใดผ่าน > 120 วันติด | ปกติ ไม่ต้องทำอะไร — เงินสดคือสถานะ |
| กลไกไม่ทำกำไรเหนือ benchmark ติดกัน 3 ปี | ทบทวนว่ากลไกตายหรือยัง (E32-depth §4 แสดงว่า edge ตายได้จริง) |
| เหรียญใดคิดเป็น > 25% ของกำไรสะสม | ตรวจว่าเป็นสภาพคล่องปลอมหรือไม่ (ดูกรณี LUNC ใน §4) |

## 2. ตัวเลขที่วัดได้จริง — 30 เหรียญที่ไม่เคยถูกใช้ออกแบบ

ต่อเนื่อง 2018-08-08 → 2026-08-05 · ทุน 10,000 · ไม่มี leverage

| | **setup นี้** | equal-weight buy & hold | BTC buy & hold |
|---|---|---|---|
| CAGR | **25.8%** | 21.3% | 33.8% |
| worst drawdown | **54.4%** | 89.1% | 76.6% |
| MAR | **0.48** | 0.24 | 0.44 |
| Sharpe | **0.80** | 0.66 | 0.79 |
| Sortino | **1.08** | 0.87 | 1.06 |
| เวลาอยู่ใต้จุดสูงสุด | **832 วัน** | 1,714 วัน | 846 วัน |
| เวลาอยู่ในตลาด | 93% | 100% | 100% |
| liquidation / ล้างพอร์ต | 0 / 0 | 0 / 0 | 0 / 0 |

**เทียบที่ความเสี่ยงเท่ากัน**: BTC ที่ลดขนาดจน drawdown เท่ากัน 54.4%
(ถือ 19% + เงินสด 81%) ให้ CAGR **13.3%** — setup นี้ให้ 25.8% ที่ความเสี่ยงเดียวกัน

**รายปี** (ชนะ benchmark 5/8)

| ปี | setup | eq-wt B&H | ส่วนต่าง | DD |
|---|---|---|---|---|
| 2018-08 | +27.5% | −5.3% | **+32.8** | 23.2% |
| 2019-08 | +54.6% | +60.7% | −6.2 | 28.2% |
| 2020-08 | +165.2% | **+949.5%** | −784.3 | 23.7% |
| 2021-08 | −19.7% | −28.3% | +8.6 | 44.7% |
| 2022-08 | −5.5% | −38.3% | **+32.8** | 30.2% |
| 2023-08 | +40.8% | +8.1% | **+32.7** | 36.7% |
| 2024-08 | +24.3% | +29.0% | −4.8 | 33.2% |
| 2025-08 | −23.4% | −72.1% | **+48.7** | 36.8% |

**รูปทรงของมันชัดมาก**: แพ้ยับปีกระทิงสุดขั้ว (2020-08 แพ้ 784 จุด) ชนะทุกปีที่เหลือ
โดยเฉพาะปีที่ตลาดเจ็บ — **นี่คือรูปทรงเดียวกับที่คลังหลักฐานนี้เจอมาตั้งแต่ E26**

**ความคงทน**

| การทดสอบ | ผล |
|---|---|
| timing luck (เลื่อนวันเริ่ม 12 แบบ) | ช่วงกว้าง **8.3 จุด** (Donchian 2x = 25.5) |
| execution lag 1 วัน | **ดีขึ้น** 25.8% → 28.5% |
| edge ครึ่งหลังของข้อมูล | **+21.5%** (ไม่ตาย) |
| breadth | **21 ชื่อกำไร / 9 ชื่อขาดทุน** จาก 30 |
| การกระจุกตัวรายเหรียญ | top-1 **LINK 14.9%** · top-3 36.8% · top-5 54.2% |
| ผู้ชนะรายปี | เปลี่ยนทุกปี: BNB → LINK → DOGE → UNI → XRP → LINK → AAVE |

## 3. สิ่งที่ setup นี้ **ไม่ผ่าน** (อ่านก่อนเชื่อตัวเลขข้างบน)

| เกณฑ์ที่ตก | ตัวเลข | ความหมาย |
|---|---|---|
| **H10 Deflated Sharpe** | **0.885** (ต้องการ ≥ 0.95) | หลังหักภาระที่ผมดู variant มา 34 แบบ Sharpe 0.80 **ยังแยกจากโชคไม่ได้ที่ระดับความมั่นใจมาตรฐาน** |
| **H6 การกระจุกตัว (ตามนิยามที่ประกาศ)** | top-1 episode 85% | นิยามนี้วัดผิดสำหรับตะกร้า (ดู VALIDATION_LOG E33) แต่ **ประกาศไว้แล้วจึงนับว่าตก** — ห้ามแก้นิยามย้อนหลัง |
| **การเลือก arm นี้เป็น post-hoc** | — | setup ที่ประกาศไว้จริงคือเวอร์ชันมี screen ซึ่ง **ไม่ผ่าน 6/10** · การหันมาใช้ arm ที่ปิด screen คือการเลือกหลังเห็นผล |

**และอคติที่แก้ไม่ได้ด้วยข้อมูลชุดนี้**

1. **Survivorship bias** — จักรวาลมาจากรายชื่อที่ Binance ลิสต์วันนี้ ผลตะกร้า**ดีเกินจริงเป็นระบบ**
2. **ช่วงเวลาเดียว** 2017–2026 มี bull cycle ใหญ่สองรอบ ไม่ใช่ตัวอย่างอิสระ 8 ปี
3. **LUNC ให้ +21.8% จากการถือ 490 วัน** และเป็น 21.9% ของหน้าต่าง 2025-08 — เหรียญที่
   ล่มจริงและสภาพคล่องต่ำมาก · สมมติฐาน 0.15%/ขา **ไม่สมจริงสำหรับมัน** ตัดออกแล้ว
   ตัวเลขจะต่ำลง (ยังไม่ได้วัดว่าเท่าไหร่)
4. **ไม่มี slippage ตามขนาด** — ทุนใหญ่ขึ้นตัวเลขจะแย่ลง และเหรียญเล็กจะเทรดไม่ได้จริง

## 4. บทเรียนที่แพงที่สุดจาก E33 (สำคัญกว่าตัวเลข)

**หลักฐานที่แข็งที่สุดที่ผมมี แปลงเป็นกฎการเทรดแล้วผิด**

E32-depth §1 วัดได้ชัดว่าสถานะ "เหนือ/ใต้ SMA-200" มีข้อมูลจริง (ช่องว่าง 0.12–0.54%/วัน
และหางซ้ายอยู่ใต้เส้น) ผมจึงสร้าง **screen** ที่รับเฉพาะเหรียญที่สถิตินี้เป็นบวก
ในอดีต 730 วัน · ผลคือ:

| horizon | ชื่อที่ screen เก็บ | ชื่อที่ screen ตัดทิ้ง |
|---|---|---|
| 30 วัน | +4.1% | **+6.6%** |
| 90 วัน | +16.3% | **+26.5%** |
| 180 วัน | +40.4% | **+69.8%** |

**screen ตัดทิ้ง 54% ของชื่อที่ trend เป็นบวก และชื่อที่มันตัดทิ้งทำได้ดีกว่าทุกช่วงเวลา**
เพราะสถิติย้อนหลัง 730 วันจะตัดเหรียญที่เพิ่งผ่านสองปีแย่ออก **พอดีตอนที่มันกำลังจะฟื้น**

> **"สถานะมีข้อมูล" ≠ "สถิติของสถานะในอดีตใช้คัดสินทรัพย์ได้"**
> การกระโดดจากข้อแรกไปข้อสองคือความผิดพลาด และมันวัดได้ ไม่ใช่ความเห็น
