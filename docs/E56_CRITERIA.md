## 1. แขนที่ทดสอบ (ประกาศครบ ห้ามเพิ่มหลังเห็นผล)

**intrabar** ∈ `tp_first` (สเปก) · `sl_first` (ร้าย)
**กฎ BE-arming-bar** ∈ `coded` (แท่งที่ arm BE รอด — กฎที่ E44–E55 ใช้) ·
`literal` (แท่งที่ arm BE โดน stop ที่ BE ได้ — อ่านสเปกตามตัวอักษร)
**ต้นทุน/ข้าง** ∈ `0.05%` · `0.10%` · `0.15%` · `0.25%` (เพดานเดียวกับ E50
ไม่ได้เลือกจากผล)

= **16 ชุด** รายงานครบทุกชุด ทุกช่วง (IS / OOS / เต็ม) เสมอ
ไม่แตะ entry / stop / target / ขนาดไม้ / warmup

**มุมร้ายที่สุดที่ประกาศไว้ล่วงหน้า** = (`sl_first`, `literal`, ต้นทุนที่ระบุในแต่ละข้อ)

## 4. สิ่งที่จะไม่ทำ

- ไม่จูนอะไรเพื่อชดเชย (ขยาย TP / กรอง R เล็ก / เลี่ยงเหรียญที่แพ้) — E46
  พิสูจน์แล้วว่าการจูนหลังเห็นผลไม่ทรานสเฟอร์
- **ไม่แก้กฎ BE-arming-bar ในโค้ดหลัก** — E55 D ตัดสินไปแล้วว่าคงไว้และรายงาน
  แบบตัวอักษรเป็น error bar · E56 คือการรายงานนั้น ไม่ใช่การกลับคำ
- ไม่รายงานเฉพาะช่องที่ดูดี — **16 ช่อง ทุกช่วง เสมอ**
- ไม่อ้างว่ามุมร้ายที่สุด = ความจริง มันคือ**ขอบล่าง** ความจริงอยู่ระหว่างขอบทั้งสอง
  และช่วงนั้นคือสิ่งที่ต้องรายงาน ไม่ใช่ตัวเลขเดียว
- ไม่ใช้ S017 / overlay ที่ไหนเลย (E55 ปฏิเสธทั้งคู่) — วัดบน **S003 เปล่า** เท่านั้น
- ไม่มีคำสั่งจริง ไม่มี promote ไม่ลดเกณฑ์ ValidationGate
