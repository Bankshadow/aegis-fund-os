## 3. นิยาม swing (ล็อกไว้ ห้ามเพิ่มหลังเห็นผล)

**Fractal pivot**: แท่ง `i` เป็น swing high เมื่อ `high[i]` สูงกว่า `high` ของ
**L แท่งก่อนหน้าและ L แท่งถัดไป** ทั้งหมด (swing low นิยามกลับกันด้วย `low`)

- **L ∈ {5, 10, 20}** — สั้น/กลาง/ยาว ค่ามาตรฐาน ไม่ได้ fit กับข้อมูลชุดนี้
- swing = pivot คู่ติดกันคนละชนิด (low→high = swing ขาขึ้น, high→low = ขาลง)
- pivot ที่แท่ง `i` **ยืนยันได้ที่แท่ง `i+L`** — โซนใช้ได้ตั้งแต่นั้น

## 5. สิ่งที่วัด

เมื่อราคา**แตะโซนครั้งแรก** (หลัง `i+L`) บันทึก:

- **ผลตอบแทนล่วงหน้า** 5 / **10** / 20 แท่ง ในทิศทางที่ swing บอก
  (retrace ของ swing ขาขึ้น → วัดทิศขึ้น, ขาลง → วัดทิศลง)
- **hit rate**: ผลตอบแทนล่วงหน้า > 0
- **ตัวเทียบฐาน**: ผลตอบแทนล่วงหน้าจาก**ทุกแท่ง** (unconditional) ในทิศเดียวกัน
- **bootstrap** 10,000 ครั้ง สุ่มแท่งจำนวนเท่ากันจากฐาน → percentile

**Primary test (ประกาศไว้ก่อน มีข้อเดียว):**
> **Z3 ที่ horizon 10 แท่ง บน L=10 — bootstrap percentile เทียบ Z5 (สุ่ม)**

ที่เหลือทั้งหมดคือ robustness ไม่ใช่หลักฐานหลัก
