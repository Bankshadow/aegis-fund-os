## 0. คำถาม

E34 K6 ผ่าน: ตัวกรองเทรนด์แบบเข้า/ออกชนะ constant-mix ที่ exposure เท่ากัน
→ ตัวกรองมีข้อมูลจริง แต่รูปแบบ binary ทิ้งข้อมูล**ขนาด**ของความแรง

> **ถือแบบไล่ระดับตามความแรงของเทรนด์ดีกว่าถือแบบเข้า/ออก หรือไม่**

## 1. ข้อมูล

| รายการ | ค่า |
|---|---|
| Primary | `data/btc_daily_full.json` — BTCUSDT 1d |
| Held-out | ETH, SOL — **ห้ามแตะจนกว่า R2–R6 ผ่านครบ** |
| Warm-up | 252 · OOS 252 ไม่ทับกัน · cadence รายเดือน (21) |
| ต้นทุน | 0.15%/ขา ตามขนาดที่เปลี่ยน (เอนจิน cadence) |

## 2. แขน (ล็อก)

| id | กฎ |
|---|---|
| A0 | buy & hold |
| A1 | binary: 1 เหนือ SMA-200, 0 ใต้ (E34 C2) |
| **A2** | **graded: weight = percentile rank ของ (close/SMA200 − 1) ในหน้าต่าง 252** |
| A3 | inverse-vol (target 40%/ปี, clip [0,1]) — control ความเสี่ยง |
| A4 | constant-mix ที่ mean exposure ของ A1 — control K6 |
| A2s | A2 ปรับสเกลด้วยสถิติ warm-up เท่านั้น (robustness) |

## 3. เกณฑ์ (R1–R7)

| id | เกณฑ์ |
|---|---|
| P1/R1 | Spearman(เดไซล์ความแรง, fwd 21d) และการจัดเรียงมีสาระ (permutation) |
| **R2** | **A2 mean robust > A1** และชนะใน >50% ของหน้าต่าง — **คำถามหลัก** |
| R3 | A2 mean robust > 0 |
| R4 | A2 > A4 constant-mix |
| R5 | A2 > A3 inverse-vol |
| R6 | A2 > A0 buy&hold |
| R7 | held-out ETH+SOL — แตะเมื่อ R2–R6 ผ่าน |

**ผ่าน promote = R2–R7 ครบ** · R2 ผ่านแต่ R3 ตก = ⚖️ ความคืบหน้าเชิงกลไก ไม่ promote
