# Offer

Walk-Forward Lab is an **education / analytics** tool that uses the same
grid engine to teach **why a grid loses** on daily AOT. It is not a live trading bot
and it is not live-trading ready.

Included:

- `/walk-forward` — per-fold OOS table, verdict vs the gate, summary tiles
- `/walk-forward-compare` — E26 → E28 → E29 with the honest mechanism narrative
- Interactive cost model (Thai retail / zero / heavy)
- `/walk-forward-overfit` — in-sample geometry selection is no better than chance

Not included:

- Live order routing, withdrawals, or third-party capital management
- A promoted dual/RL default
- A promise that fees are the reason the grid loses (measured false here)
- A promise that picking the in-sample winner helps OOS (measured as chance)

Price / packaging for students is an operator decision and is not set in
this file. The product surface stays read-only research until Phase 3
private-fund gates clear — and those gates are **not** cleared.
