# Voice

Write copy to match **measured** claims. If a lesson feels better than the
fold table, the copy is wrong.

Allowed:

- "The grid does what it is designed to do: it wins crash folds and loses
  trending-up folds."
- "Fees are not the cause here."
- "Picking the in-sample geometry is worth nothing on this set."
- Thai + English education copy that names mechanisms in plain language.

Forbidden:

- Invented metrics, unverified ROI, "set and forget" live-grid promises
- Promoting Dual 75/25 or RL as a production default
- Softening E20–E29 into "almost" or "needs a bit more tuning"
- Sponsored-tool voice (Higgsfield, Smartlead, Meta Ads Manager) as if
  those were part of this product
