# Vault — authoritative source of truth

A Grok Bot's memory holds preferences and summaries. Memory is **not** a
substitute for an authoritative source. These markdown files are that source
for this repo.

| File | Owns |
|---|---|
| `offer.md` | What we sell, what is included, what we are not |
| `icp.md` | Who this is for, qualified vs bad-fit |
| `refuse.md` | Hard refusals (constitution) |
| `rulings.md` | Dated decisions we do not re-argue |
| `voice.md` | How copy is allowed to speak |

Session notes live in `STATE.md`. They are compost, not the offer.
Experiment evidence lives in `docs/VALIDATION_LOG.md`. Education pages
must not drift from `src/lib/aot-walkforward.ts`.

Lanes: `docs/GROK_BOT_LANES.md` and `python agent/lanes.py`.
