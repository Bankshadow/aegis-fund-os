## 1. นิยามที่ล็อกก่อนรัน

**buy & hold**: ซื้อ SOL 50% / LINK 50% ที่ราคาปิดวันแรกของหน้าต่าง **ไม่ rebalance**
ถือถึงวันสุดท้าย · ไม่มีค่าธรรมเนียม (เข้าข้าง buy&hold โดยตั้งใจ)

**S003**: **ปลายร้าย** = `sl_first` @ **0.15%**/ข้าง (มุมของ E56) เป็นแขนหลัก
· **ปลายสเปก** = `tp_first` @ 0.05% รายงานเป็นเพดานเสมอ · ไม่มี cooldown
ไม่มี overlay (E55 ปฏิเสธทั้งคู่)

**หน้าต่าง** (ประกาศครบ ห้ามเพิ่ม):

| ชื่อ | ช่วง | เหตุผล |
|---|---|---|
| **W_OOS** (หลัก) | 2022-08-01 → 2026-08-13 | หน้าต่างเดียวกับ E50 Y3 / E56 Z4 ที่ตกไป |
| W_COMMON | 2020-04-10 → 2026-08-13 | วันแรกที่ **SOL มีข้อมูล** — ก่อนหน้านี้ buy&hold 50/50 ไม่มีตัวตน |

**ห้ามอ้างหน้าต่าง "เต็มประวัติ" กับ buy&hold** — LINK มีตั้งแต่ 2017 แต่ SOL
ไม่มี การใส่ 2017–2020 เข้าไปคือการให้ buy&hold ถือเหรียญเดียวแล้วเรียกว่า 50/50

**การจับคู่ขนาด (matched sizing)**: คาลิเบรต risk/ไม้ของ S003 **ครั้งเดียวบน
เส้นทางจริงของแต่ละหน้าต่าง** ให้ maxDD เท่ากับ maxDD ของ buy&hold ในหน้าต่างนั้น
แล้ว **ตรึงค่านั้นไว้ตลอด bootstrap ทุกเส้น** (ไม่คาลิเบรตซ้ำต่อเส้น)

**Paired moving-block bootstrap**: สุ่ม**บล็อกวัน** ยาว **20 วัน** แบบใส่คืน
ให้ครบความยาวเดิม × **500 เส้น** (seed 6000+i) · **ใช้ลำดับบล็อกเดียวกันกับทั้ง
S003 และ buy&hold ในทุกเส้น** — เทียบสองกลยุทธ์บนประวัติศาสตร์ที่ถูกสับแบบเดียวกัน
ไม่ใช่คนละชุด

**ข้อจำกัดที่ต้องเปิดเผยทุกครั้ง**: ผลตอบแทนรายวันของ S003 ลงบัญชี**เฉพาะวันที่
ปิดไม้** (ไม่มี mark-to-market ระหว่างถือ) จึงกระจุกกว่าความจริง ⇒ **maxDD ของ
S003 ถูกประเมินต่ำกว่าความจริงอย่างเป็นระบบ** ในการเทียบนี้ ซึ่ง**เข้าข้าง S003**
ต้องระบุคู่กับผลทุกครั้ง

**robust score** = `total return − 2 × maxDD` ตามกฎในโปรเจกต์

## 4. สิ่งที่จะไม่ทำ

- ไม่เพิ่มหน้าต่าง ไม่เพิ่มเกณฑ์ ไม่ปรับ 90%/60% หลังเห็นผล
- ไม่คิดค่าธรรมเนียมให้ buy&hold (ให้แต้มต่อ) และ**ไม่ลด**ค่าธรรมเนียมของ S003
- ไม่ใช้ S017 / overlay · ไม่จูน entry/exit/stop/target
- ไม่รายงานเฉพาะปลายที่ดูดี — **ปลายร้ายเป็นแขนหลักเสมอ ปลายสเปกเป็นเพดาน**
- ไม่อ้างว่า bootstrap = อนาคต · ไม่ปิดบังว่า maxDD ของ S003 ถูกประเมินต่ำ
  เพราะไม่มี mark-to-market ระหว่างถือ
- ไม่ promote · ไม่มีคำสั่งจริง · ไม่ให้คำแนะนำการลงทุนรายบุคคล
