# Agent Lessons — บทเรียนจากการถูกแก้

> บันทึกเฉพาะ **การแก้ที่ผู้ใช้บอกตรง ๆ** พร้อมหลักฐานว่าเกิดอะไรขึ้นจริง
> คำชมหรือการตอบรับ ("ได้", "โอเค", "perfect") **ไม่ถูกบันทึก** — การตอบรับ
> ไม่เท่ากับการรับรองว่าถูก และผลลัพธ์ในโปรเจกต์นี้ตัดสินด้วย gate เท่านั้น
>
> ไฟล์กฎ (`CLAUDE.md`, `AGENTS.md`), เกณฑ์ที่ประกาศแล้ว
> (`docs/AOT_VALIDATION_CRITERIA.md`), สมุดหลักฐาน (`docs/VALIDATION_LOG.md`)
> และ `gate/` **ห้ามแก้จากที่นี่** — ดู `agent/reflect.py`

### ก่อนบอกผู้ใช้ว่างานพร้อมให้คนอื่นใช้

- **กฎ:** ตรวจ environment จริงที่ผู้ใช้จะเปิด (URL production) ก่อนพูดเสมอ — local ผ่านไม่ได้แปลว่าใช้ได้
- **หลักฐาน:** บอกให้เอาลิงก์ Walk-Forward Lab ไปให้นักเรียน ทั้งที่ทั้ง 3 route ยังเป็น 404 บนเว็บจริง เพราะ deploy ผูกกับ main แต่งานอยู่บน branch ที่ยังไม่ merge
- **บันทึกเมื่อ:** 2026-07-26

### ก่อนเสนอทางเลือกให้ผู้ใช้ตัดสินใจ

- **กฎ:** ตรวจว่าทางเลือกนั้นทำได้จริงก่อนเสนอ อย่าเสนอแล้วค่อยไปเจอว่าเป็นไปไม่ได้
- **หลักฐาน:** เสนอให้แยก branch เฉพาะ Walk-Forward Lab แล้วมาพบทีหลังว่า main ไม่มี aot-backtest.ts เลย (+1009 บรรทัดถูกสร้างใน branch) จึงแยกไม่ได้ตั้งแต่ต้น
- **บันทึกเมื่อ:** 2026-07-26

### ก่อนเขียนคำอธิบาย/บทเรียนที่มีตัวเลขให้ผู้ใช้อ่าน

- **กฎ:** วัดจริงก่อนเขียน แล้วเขียนตามผลที่วัดได้ ห้ามเขียนตามสัญชาตญาณแล้วค่อยหาตัวเลขมารองรับ
- **หลักฐาน:** ตั้งใจสอนว่า 'grid แพ้เพราะค่าธรรมเนียม' แต่วัดแล้วพบว่าต้นทุน 0 ก็ยังแพ้ alpha -11.2 จึงต้องเขียนบทเรียนใหม่ให้ตรงหลักฐาน
- **บันทึกเมื่อ:** 2026-07-26

### เมื่อกลไกทำให้ค่าเฉลี่ยดีขึ้น

- **กฎ:** แยกดูราย fold เสมอก่อนสรุปว่ากลไกได้ผล — เช็คว่ามาจาก selection artifact หรือ fold ที่หยุดเทรดหรือไม่
- **หลักฐาน:** E29 ผ่านเกณฑ์ M1-M3 ครบบนค่าเฉลี่ย แต่ decomposition พบว่า +7.69 จาก +7.74 มาจาก fold ที่ cycles=0 (ไม่เทรด = ไม่ขาดทุน)
- **บันทึกเมื่อ:** 2026-07-26

### เมื่อประเมินความรุนแรงของปัญหา performance บน serverless

- **กฎ:** ถามว่ามันทำให้ 'พัง' หรือแค่ 'ช้า' — CPU limit ของ Worker ทำให้งานหนักกลายเป็น error ไม่ใช่แค่รอนาน
- **หลักฐาน:** รายงาน 8.9 วิ CPU ต่อ request ว่าเป็นเรื่องช้า/เปลือง แล้วใส่ cache ซึ่งไม่ช่วย cold isolate — ที่ถูกคือ precompute ตอน build
- **บันทึกเมื่อ:** 2026-07-26
