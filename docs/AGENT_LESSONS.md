> บันทึกเฉพาะ **การแก้ที่ผู้ใช้บอกตรง ๆ** พร้อมหลักฐานว่าเกิดอะไรขึ้นจริง
> คำชมหรือการตอบรับ ("ได้", "โอเค", "perfect") **ไม่ถูกบันทึก** — การตอบรับ
> ไม่เท่ากับการรับรองว่าถูก และผลลัพธ์ในโปรเจกต์นี้ตัดสินด้วย gate เท่านั้น
>
> ไฟล์กฎ (`CLAUDE.md`, `AGENTS.md`), เกณฑ์ที่ประกาศแล้ว
> (`docs/AOT_VALIDATION_CRITERIA.md`), สมุดหลักฐาน (`docs/VALIDATION_LOG.md`)
> และ `gate/` **ห้ามแก้จากที่นี่** — ดู `agent/reflect.py`

### ก่อนบอกผู้ใช้ว่างานพร้อมให้คนอื่นใช้

- **กฎ:** ตรวจ environment จริงที่ผู้ใช้จะเปิด (URL production) ก่อนพูดเสมอ — local ผ่านไม่ได้แปลว่าใช้ได้
- **หลักฐาน:** บอกให้เอาลิงก์ Walk-Forward Lab ไปให้นักเรียน ทั้งที่ทั้ง 3 route ยังเป็น 404 บนเว็บจริง เพราะ deploy ผูกกับ main แต่งานอยู่บน branch ที่ยังไม่ merge
- **บันทึกเมื่อ:** 2026-07-26

### ก่อนเสนอทางเลือกให้ผู้ใช้ตัดสินใจ

- **กฎ:** ตรวจว่าทางเลือกนั้นทำได้จริงก่อนเสนอ อย่าเสนอแล้วค่อยไปเจอว่าเป็นไปไม่ได้
- **หลักฐาน:** เสนอให้แยก branch เฉพาะ Walk-Forward Lab แล้วมาพบทีหลังว่า main ไม่มี aot-backtest.ts เลย (+1009 บรรทัดถูกสร้างใน branch) จึงแยกไม่ได้ตั้งแต่ต้น
- **บันทึกเมื่อ:** 2026-07-26

### ก่อนเขียนคำอธิบาย/บทเรียนที่มีตัวเลขให้ผู้ใช้อ่าน

- **กฎ:** วัดจริงก่อนเขียน แล้วเขียนตามผลที่วัดได้ ห้ามเขียนตามสัญชาตญาณแล้วค่อยหาตัวเลขมารองรับ
- **หลักฐาน:** ตั้งใจสอนว่า 'grid แพ้เพราะค่าธรรมเนียม' แต่วัดแล้วพบว่าต้นทุน 0 ก็ยังแพ้ alpha -11.2 จึงต้องเขียนบทเรียนใหม่ให้ตรงหลักฐาน
- **บันทึกเมื่อ:** 2026-07-26

### เมื่อกลไกทำให้ค่าเฉลี่ยดีขึ้น

- **กฎ:** แยกดูราย fold เสมอก่อนสรุปว่ากลไกได้ผล — เช็คว่ามาจาก selection artifact หรือ fold ที่หยุดเทรดหรือไม่
- **หลักฐาน:** E29 ผ่านเกณฑ์ M1-M3 ครบบนค่าเฉลี่ย แต่ decomposition พบว่า +7.69 จาก +7.74 มาจาก fold ที่ cycles=0 (ไม่เทรด = ไม่ขาดทุน)
- **บันทึกเมื่อ:** 2026-07-26

### เมื่อประเมินความรุนแรงของปัญหา performance บน serverless

- **กฎ:** ถามว่ามันทำให้ 'พัง' หรือแค่ 'ช้า' — CPU limit ของ Worker ทำให้งานหนักกลายเป็น error ไม่ใช่แค่รอนาน
- **หลักฐาน:** รายงาน 8.9 วิ CPU ต่อ request ว่าเป็นเรื่องช้า/เปลือง แล้วใส่ cache ซึ่งไม่ช่วย cold isolate — ที่ถูกคือ precompute ตอน build
- **บันทึกเมื่อ:** 2026-07-26

### เมื่อเขียนเกณฑ์ที่ตรวจอนุกรมทั้งชุด (time series) ไม่ใช่ค่าเดียว

- **กฎ:** ระบุ **ช่วงของอนุกรมที่ตรวจ** ลงในเกณฑ์ ไม่ใช่แค่ค่า tolerance — ถ้าไม่ระบุ เกณฑ์จะตกด้วยเหตุที่ไม่มีทางกระทบผลลัพธ์ และทำให้ต้องเลือก ระหว่างแก้ tolerance หลังเห็นผล (ห้าม) กับทิ้งการทดลองทั้งตัว
- **หลักฐาน:** E57 R0 ประกาศว่า ATR ของ backtrader ต้องต่างจากของเรา <= 0.5% 'ทุกแท่ง' แล้วตกที่ 21.1% (SOL) / 5.8% (LINK) แต่ความต่างอยู่เฉพาะ ช่วง seed ของ Wilder ATR: แท่งสุดท้ายที่ต่างเกิน 0.5% คือ index 75 และ 37 ส่วน warmup ของกลยุทธ์คือ 201 ตั้งแต่แท่งที่มีสัญญาณได้จริง ความต่างสูงสุดคือ 1.4e-7 และ 3.9e-8 คือเท่ากันในทางปฏิบัติ เกณฑ์วัดรวมช่วงที่ไม่มีทางกระทบอะไรเลย
- **บันทึกเมื่อ:** 2026-08-16

### ก่อนแสดงการเทียบสองกลยุทธ์ที่คำนวณจากเส้นทางจริงเส้นเดียว

- **กฎ:** อย่านำเสนอเป็นข้อสรุป ต้อง resample ก่อน (paired bootstrap ให้สอง ฝั่งเจอประวัติศาสตร์ที่ถูกสับชุดเดียวกัน) — เส้นทางเดียวให้คำตอบที่ ผิดเครื่องหมายได้ ไม่ใช่แค่คลาดเคลื่อน
- **หลักฐาน:** แสดงให้ผู้ใช้เห็นว่าที่ maxDD เท่ากัน S003 ให้ +115% เทียบ buy&hold +49% แล้วสรุปว่าชนะสองเท่า ต่อมา E58 รัน paired moving-block bootstrap 20 วัน x 500 เส้น พบว่า S003 ชนะด้าน ความมั่งคั่งเพียง 57% ของเส้น ต่ำกว่าเกณฑ์ 60% ที่ประกาศไว้ก่อนรัน และบนหน้าต่าง W_COMMON ชนะเพียง 10.4% (buy&hold +4042% vs S003 -13%) ความได้เปรียบสองเท่านั้นคือลำดับเหตุการณ์ที่บังเอิญ
- **บันทึกเมื่อ:** 2026-08-16

### ก่อนเสนอให้เปลี่ยนชื่อ (rename) สิ่งที่ชื่อดูทำให้เข้าใจผิด

- **กฎ:** อ่านโค้ดให้ครบก่อนว่าชื่อนั้นครอบคลุมพฤติกรรมกี่อย่าง — ชื่อที่ 'ไม่ครบ' กับชื่อที่ 'ผิด' แก้คนละแบบ ชื่อที่ไม่ครบให้แก้ด้วย docstring และเทสต์ การ rename จะซ่อนพฤติกรรมที่ชื่อเดิมอธิบายถูกอยู่แล้ว
- **หลักฐาน:** เสนอให้เปลี่ยน intrabar='sl_first' เป็น 'be_literal' เพราะ E56/E57 พบว่ามันเท่ากับกฎ break-even ตามตัวอักษร แต่พออ่านโค้ดพบว่า sl_first ทำสองอย่าง: (1) tie-break TP3 กับ stop และ (2) BE stop ทำงานในแท่งที่ arm — และ (1) ยังทำงานจริงเมื่อ be_rule='none' การ rename จะซ่อนมัน อีกทั้งพบว่าที่ E56 นับได้ 0 ครั้งเป็นเรื่อง เชิงโครงสร้าง (TP2 อยู่ระหว่าง entry กับ TP3 แท่งที่ถึง TP3 จึงแตะ TP2 เสมอ) ไม่ใช่ผลเชิงประจักษ์อย่างที่ log เขียนไว้
- **บันทึกเมื่อ:** 2026-08-16
