## 2. กฎที่ลอกมาตรง ๆ จากสเปก (ห้ามดัดแปลง)

**จำแนกแท่ง** เทียบแท่งก่อนหน้า `(H1, L1)`:
`inside(1)` / `outside(3)` / `2U` (H>H1, L≥L1) / `2D` (L<L1, H≤H1) + fallback ตามสเปก §2

**เข้า** ที่ **close ของแท่งสัญญาณ** (ไม่ใช่ open ถัดไป):
- `2U` และ `close < open` และไม่ใช่ doji → **SHORT**
- `2D` และ `close > open` และไม่ใช่ doji → **LONG**
- doji: `|close − open| < 1e-12` → ข้าม
- **หนึ่ง position ต่อเหรียญ** · SOL กับ LINK เดินอิสระ

**ตัวกรองล็อกปิดหมด**: `regime=none`, `vol_gate=off`, `trap_strength=off`,
`cooldown_bars=0`, `side_mode=both`

**Stop / R** (`SL_BUFFER=0.25`, `min_stop_atr=0.5`, `max_risk_atr=3.0`, Wilder ATR14):
- LONG: `stop = min(low − 0.25·ATR, close − 0.5·ATR)`, บังคับ `close − stop ≥ 0.5·ATR`, `R = close − stop`
- SHORT: `stop = max(high + 0.25·ATR, close + 0.5·ATR)`, บังคับ `stop − close ≥ 0.5·ATR`, `R = stop − close`
- ข้ามเทรดถ้า `R ≤ 0` หรือ `R > 3.0·ATR`

**เป้า** (เต็มไม้ ไม่มี scale-out): `TP1/2/3 = entry ± 1R/2R/3R`

**การจัดการ**:
1. **แท่งที่เข้าไม้ ห้ามประเมิน SL/TP** — เริ่มจัดการแท่งถัดไป
2. BE rule = `after_tp2`: แท่งใดแตะ TP2 → เลื่อน stop มาที่ entry
3. หลัง TP1 ไม่ขยับ stop
4. ออกเมื่อ TP3 / SL / BE_SL / จบข้อมูล (EOD)
5. **โมเดลในแท่ง (primary) = optimistic TP-first**: แท่งเดียวแตะทั้ง TP3 และ SL → นับ **TP3**
6. **BE แท่งเดียวกัน**: ถ้า BE ถูกติดอาวุธในแท่งที่แตะ stop ใหม่ด้วย → **ไม่ stop out ในแท่งนั้น**

**ค่าธรรมเนียม** 0.05%/ขา: `fee_R = (2 × 0.0005 × entry) / R` · `pnl_R_net = pnl_R_gross − fee_R`
